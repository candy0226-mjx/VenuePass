# 热门场馆与热门资源统计

## 功能说明

系统使用 Redis ZSet 统计场馆和资源热度，用于首页推荐、后台运营分析和排行榜展示。

## Redis Key

```text
rank:venue:hot
rank:seat:hot
```

## 行为权重

```text
浏览场馆：+1
创建订单：+5
支付订单：+10
核销完成：+8
提交点评：+6
```

场馆热度来自浏览、下单、支付、核销、点评等行为。资源热度来自下单、支付、核销等预约行为。

## 查询接口

```http
GET /api/venues/hot?limit=10
GET /api/venues/hot-seats?limit=10
```

两个接口都基于 Redis ZSet 倒序查询，返回热度最高的场馆或资源。

## 简历描述

基于 Redis ZSet 构建热门场馆与热门资源排行榜，按浏览、下单、支付、核销、点评等用户行为设置不同权重，实现可用于首页推荐和后台运营分析的实时热度统计。
